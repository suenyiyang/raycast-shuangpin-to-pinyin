# 双拼转全拼（Raycast）

一个完全本地运行的 Raycast 扩展：读取当前选中的双拼编码，按所选双拼方案转换为全拼，并通过回车直接替换原选区。

## 使用方式

1. 在飞书或其他 App 中选中已经上屏的双拼编码，例如 `syyiyh`；内容中也可以混有中文、空格或标点。
2. 打开 Raycast，执行“**双拼转全拼**”。建议为命令设置全局快捷键。
3. 顶部输入框会载入选中的双拼，也可以直接在这里输入或修改；全拼候选会实时更新。
4. 在右上角选择双拼方案，预览全拼候选。
5. 按回车，Raycast 会关闭并将候选结果粘贴到原选区。

如果 App 没有向 Raycast 暴露选中文本，扩展可以回退读取剪贴板。此时先按 `⌘C`，再运行命令即可。没有选区和剪贴板内容时，也可以直接在顶部输入框中输入双拼。

## 支持的 Apple 双拼布局

- 小鹤双拼
- Apple 默认
- 搜狗双拼
- 拼音加加
- 微软双拼
- 常用双拼

默认方案可以在 Raycast 的扩展设置中配置，也可以在转换界面按 `⌘P` 临时切换。界面会记住最近使用的方案。

## 快捷操作

- `↵`：将当前全拼候选粘贴到原选区
- `⌘C`：仅复制当前全拼候选
- `⌘P`：切换双拼方案
- `⌘R`：重新读取选中文本

## 隐私

所有转换都在本机完成，不访问网络，不上传选中文本。

## 本地开发

```bash
npm install
npm test
npm run lint
npm run build
npm run dev
```

`npm run dev` 会把开发版扩展加载到本机 Raycast。首次读取或替换其他 App 的选中文本时，请确保 Raycast 已获得 macOS“辅助功能”权限。

## 转换规则

扩展根据 Apple 当前六种双拼键盘布局建立反向音节表。连续的英文字母（以及支持方案中的 `;` 键）每两个字符被视为一个完整双拼音节；中文、空格、标点等其他字符会作为边界并原样保留。最后只输入了一个按键时，会先按当前方案转换声母，例如小鹤双拼中的 `v` 会转换为 `zh`。若一个编码存在多个合法全拼展开，界面会列出所有候选供用户选择。
